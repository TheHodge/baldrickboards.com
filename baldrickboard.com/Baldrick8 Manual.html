Baldrick8 Manual

Everything you need to wire, network and run your Baldrick8 — from first power-up to your first show.

01Introduction

The Baldrick8 is an 8-output pixel controller built for professional displays and large-scale installs. This manual walks you through everything from unboxing to your first running show.

If you've used a smart pixel controller before, most of this will feel familiar — the Baldrick8 speaks DDP, Art-Net, E1.31 and sACN, hosts its own web interface, and needs no Raspberry Pi or FPP licence. If this is your first board, work through the sections in order and you'll be lighting pixels in a few minutes.

New here?Start with Powering the board and follow each step. The whole process takes about ten minutes.

02What's in the box

Every Baldrick8 ships with the essentials to get started. Check you have everything before you begin:

  • 1 × Baldrick8 controller board (v1.1)
  • 2 × 7.5 A blade fuses (pre-fitted)
  • 8 × 3-pin pixel output connectors
  • 1 × Quick-start card with QR code to this manual
MountingFree 3D-printable mounts and enclosures are available on the STLs & Mounts page — print one before install day.

03Powering the board

The Baldrick8 has two independent power inputs accepting 5–48 V DC (up to 48 V on v1.1). Each input feeds half the outputs, so you can run different voltages for different parts of your display.

Mind the voltageNever feed mains AC into the board, and double-check polarity before powering on. Mismatched voltage is the number-one cause of "BOOM BOOM BOOM" support tickets.

Wiring the inputs

Set your supply voltage

Match your power supply to your pixels — typically 5 V or 12 V. Confirm with a multimeter before connecting.

Connect input A

Wire +V and GND into the first input terminal. The 7.5 A fuse protects this rail.

Connect input B (optional)

For full pixel runs at 100% brightness, feed the second input too. This balances current across both rails.

04Wiring pixels

Each of the eight outputs drives up to 2250 channels — that's 750 RGB pixels at 40fps. Outputs are grouped in banks with shared ground and signal pads clearly labelled G D +.

Connecting a string

  1. Match the pixel string's data, +V and ground to the D + G pads on the output.
  2. Keep the first pixel within ~3 m of the board for a clean data signal; inject power for longer runs.
  3. Repeat for each output, working left to right so your config map matches the board.
TipLabel each output cable as you go — future-you will thank present-you when troubleshooting in the dark.

05Network setup

Connect the Baldrick8 to your network over its gigabit Ethernet port. By default it requests an address over DHCP. To find it, check your router's client list or use the onboard button (see below) to announce its IP.

To set a static address, open the web interface and edit the network settings:

# Example static configuration
address  192.168.1.50
netmask  255.255.255.0
gateway  192.168.1.1
protocol DDP // or E1.31 / Art-Net / sACN
Static is safer for showsA fixed address means your controller is always where xLights or FPP expects it — no surprises on show night.

06The web interface

Point any browser at the board's IP address to reach the built-in interface. From here you can configure outputs, choose protocols, set pixel counts and run test patterns — no extra software required.

SectionWhat it does
OutputsSet pixel count, colour order and null pixels per port.
NetworkDHCP or static address, protocol and universe mapping.
TestBuilt-in patterns to verify wiring before pushing a show.
SystemFirmware version, reboot and factory reset.

07Buttons & test mode

The Baldrick8 has three programmable buttons, available both as onboard physical buttons and as input ports. Use the FPP API to start or stop a sequence, or trigger the built-in test mode to chase colours across every output.

  • Short press — cycle the active test pattern.
  • Long press — announce the board's current IP address.
  • API trigger — map a button to start/stop a sequence in FPP.

08Updating firmware

We ship improvements regularly. Update from the System tab of the web interface, or download the latest release from the Release Notes page and upload it manually.

Don't power off mid-updateWait for the board to reboot on its own. Interrupting a firmware write can leave the board needing a recovery flash.

09Troubleshooting

Most issues come down to power, data direction or network config. Start here:

SymptomLikely fix
No pixels lightCheck input voltage and that D goes to the string's data-in, not data-out.
First few pixels onlyInject power further down the run; long strings sag without it.
Board not on networkLong-press a button to announce the IP, or set a static address.
Flicker at distanceKeep the first pixel close to the board; add a level shifter for long data runs.
